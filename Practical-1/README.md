# 🎓 StudentHub Portal

> A simple and user-friendly Student Portal developed as a semester-long Web Development project.

---

## 📌 Project Overview

**StudentHub** is a web-based student portal designed to provide students with a centralized platform to access important academic and portal-related information.

The project focuses on creating a clean, responsive, and easy-to-navigate interface using modern web technologies.

---

## 🎯 Objectives

* Create a structured student portal.
* Provide simple and clear navigation between pages.
* Allow users to create an account and log in.
* Provide access to student profile and portal information.
* Maintain a well-organized project structure.
* Manage project development using Git and GitHub.

---

## ✨ Features

* 🏠 Home Page
* 🔒 User Login
